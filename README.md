# KAMUI Extended (神威) — iOS 26/27 MobileGestalt Toolbox & Sandbox Escape

Расширенная версия KAMUI с дополнительными функциями, отключением звука камеры, кнопкой Camera Control, очисткой кэшей и автосборкой IPA через GitHub Actions на macOS (`macos-latest`).

## 🚀 Новые возможности в Extended v2.5.3:
- **Mute Shutter Sound:** Отключение звука затвора камеры для устройств из Японии и Южной Кореи.
- **Camera Control Button:** Программная поддержка кнопки Camera Control (из iPhone 16).
- **Lockscreen Dimming (LGLPM):** Затемнение экрана блокировки.
- **iPad Apps on iPhone:** Включение поддержки запуска приложений для iPad на iPhone.
- **Dynamic Island Presets:** Быстрый выбор сабтайпа `iPhone Air (2736)` для минимального наложения на чёлку.
- **Clean App Caches:** В меню Настройки ➔ Инструменты добавлена быстрая очистка кэшей приложений для освобождения места в памяти.

## 📦 Сборка и Релизы:
Проект автоматически компилируется в GitHub Actions на `macos-latest`. Готовый `.ipa` файл доступен во вкладке **[Releases](https://github.com/ffefl1n/kamui-ios/releases)**.
